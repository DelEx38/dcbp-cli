## Changes Made

### 1. Ownership Model (`src/dcbp_cli/commands.py`)

Added `Ownership` enum (OWNED | UNKNOWN) with two classification criteria:

**Criterion 1 - Frontmatter marker** (primary):
- Parses YAML frontmatter block only (never body text)
- `tool: dcbp` in frontmatter → OWNED
- Regression: `tool: dcbp` only in body → UNKNOWN

**Criterion 2 - Hash + DCBP marker** (legacy v0.5.0 detection):
- SHA-256 hash matches `DCBP_V050_SKILL_HASHES` dict AND
- Content contains at least one `DCBP_SPECIFIC_MARKERS` string
- Both conditions required (hash alone insufficient)

**Conservative by design**: Everything not matching criteria 1 or 2 → UNKNOWN → NEVER TOUCHED.

### 2. `_parse_frontmatter()` (NEW)

- Parses `---` delimited YAML block at start of file
- Returns `None` if no opening `---`, missing closing `---`, or other parse error
- Never processes body text
- Handles CRLF line endings (caller normalizes before passing)
- No external YAML dependency (stdlib only)

### 3. `classify_skill(skill_dir)` (NEW)

- Returns `Ownership.OWNED` or `Ownership.UNKNOWN`
- Handles: missing SKILL.md, unreadable files (OSError/IsADirectoryError), malformed frontmatter
- All edge cases → UNKNOWN

### 4. `_install_skills_to_project()` (NEW - replaces destructive copytree)

- Never removes destination directory
- Per-skill installation:
  - Not exists → install (safe)
  - OWNED + force=True → update (safe)
  - OWNED + force=False → skip (informational)
  - UNKNOWN → PRESERVE, print warning
- `--force` only affects OWNED skills

### 5. `migrate_global_skills()` (NEW)

- Scans `~/.claude/skills/` if it exists
- Only removes OWNED entries (dirs only)
- UNKNOWN dirs → preserved
- Non-directory entries → tracked but not touched
- Returns full report dict
- Idempotent

### 6. `init_project()` (MODIFIED)

**Removed**:
- Block that created `~/.claude/skills/` (lines 419-441 in v0.5.0)
- Destructive `shutil.rmtree(skills_path)` before copy

**Added**:
- `_install_skills_to_project()` for skill-by-skill safe installation
- `migrate_global_skills()` call with `_print_migration_report()`

### 7. `update_templates()` (MODIFIED)

**Removed**:
- Block that wiped `~/.claude/skills/` and recreated it (lines 536-546)
- `shutil.rmtree(claude_skills_dst)` before copy

**Added**:
- `_install_skills_to_project(force=True)` for safe skill updates
- `migrate_global_skills()` call

### 8. `install_skills()` (DELETED)

The entire function has been removed. `dcbp install` was the primary vector for global skill destruction.

### 9. `cli.py` (MODIFIED)

Removed:
- `install_skills` import
- `install` subparser definition
- `elif args.command == "install":` branch

### 10. Skill Templates (ALL 12 MODIFIED)
